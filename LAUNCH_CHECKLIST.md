# Black Canvas Gallery launch checklist

## Already prepared

- The hosted version can run in **public-gallery-only** mode.
- In that mode, Black Canvas Studio, Prompt Library, Connections, original uploads, customer records, and all other private routes return “not found.”
- Only the Gallery, inquiry page, gallery previews, and the public gallery settings can be reached by visitors.
- The hosted gallery data folder is designed to live on Render persistent storage, so it survives restarts and updates.
- A health check is available for hosting verification.

## Before publishing

1. Review visible artwork: title, collection, description, status, and any shop link.
2. Choose the public contact email for collector inquiries.
3. Choose a custom domain when ready.
4. Create the Render account and select the small paid web service with persistent storage.
5. Transfer only the approved gallery artwork and settings to the hosted gallery.
6. Test the gallery on a phone and submit one test inquiry.
